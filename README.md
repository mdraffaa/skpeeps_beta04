#My Biggest Fullstack Project (yet)
A fully working social media app with bunch of features and optimizations

##What you'll experience 
- A combo of X/TikTok/WhatsApp all in one Application
- Smooth scrolling feeling
- Optimized mini games inside of a roomchat that you can play with ur friend(s)

##Pointers
- Sign-in with a google account
- Complete your personal account profile
- Add people you know to starts filling the feeds section
- You can also create a group chat with a bunch of added connections
